# BAS-IP AA-14FB: Автоматическая смена кодов доступа раз в две недели

Программа для автоматической регулярной смены PIN-кодов доступа на вызывных панелях **BAS-IP AA-14FB** в жилом комплексе из **4 домов (38 панелей)** с синхронизацией через **Google Таблицы** и уведомлением жильцов через **Google Почту (Gmail)**.

> 💡 **Google Cloud Console заблокирован в вашей стране?**
> **Никаких проблем!** Программа поддерживает работу **без Google Cloud Console** через встроенный **Google Apps Script** (прямо из меню Google Таблицы) или **AppSheet**. Это полностью бесплатно, не требует привязки карт и работает в любой стране мира.

---

## 🏢 Структура жилого комплекса (38 вызывных панелей)

Комплекс состоит из **4 домов** с двойными подъездами (внешняя дверь + внутренняя дверь) и **2 калиток**:

* **Калитки общего доступа (2 панели):**
  * `gate_1`: Калитка 1 (Северная/Главная)
  * `gate_2`: Калитка 2 (Южная/Въезд)
  * 🔑 *Доступ к калиткам предоставляется **ВСЕМ** жильцам автоматически!*
* **Дом 1 (6 панелей):** 3 двойных подъезда (Подъезды 1, 2, 3 по 2 панели: Дверь A и B).
* **Дом 2 (12 панелей):** 6 двойных подъездов (Подъезды 1..6 по 2 панели: Дверь A и B).
* **Дом 3 (12 панелей):** 6 двойных подъездов (Подъезды 1..6 по 2 панели: Дверь A и B).
* **Дом 4 (6 панелей):** 3 двойных подъезда (Подъезды 1, 2, 3 по 2 панели: Дверь A и B).
* **ИТОГО: 2 + 6 + 12 + 12 + 6 = 38 панелей BAS-IP AA-14FB.**

Посмотреть весь список панелей и их IP-адреса можно командой:
```bash
python3 main.py list-panels
```

## ⚙️ Где и как прописать реальные IP-адреса и пароли 38 панелей

Вы можете настроить IP-адреса и пароли панелей любым удобным для вас способом:

### Способ 1: Файл `panels.yaml` (Рекомендуемый, если у панелей разные IP/пароли)
В корне репозитория уже создан файл [`panels.yaml`](panels.yaml) со всеми 38 панелями. Откройте его в любом текстовом редакторе и укажите реальные IP и пароли:
```yaml
# Калитка 1
- panel_id: "gate_1"
  name: "Калитка 1 (Северная/Главная)"
  is_gate: true
  host: "192.168.1.10"       # <-- Реальный IP панели
  port: 80
  username: "admin"
  password: "ВашПароль"      # <-- Пароль доступа к API панели

# Дом 1, Подъезд 1 (Внешняя дверь)
- panel_id: "d1_p1_a"
  name: "Дом 1, Подъезд 1 (Внешняя дверь)"
  building: 1
  entrance: 1
  door: "A"
  host: "192.168.1.12"
  port: 80
  username: "admin"
  password: "ВашПароль"
```

### Способ 2: Файл `panels.csv` (Если удобнее редактировать в Excel)
В корне проекта также есть таблица [`panels.csv`](panels.csv), которую можно открыть в Excel или LibreOffice Calc, отредактировать столбцы `IP`, `Порт` и `Пароль`, и сохранить.
Чтобы программа читала из CSV, в `config.yaml` укажите:
```yaml
panels_file: "panels.csv"
```

### Способ 3: Быстрая генерация через `facility_topology` в `config.yaml`
Если у всех панелей одинаковый пароль и IP-адреса идут последовательно (например, `192.168.1.10` ... `192.168.1.47`), достаточно указать настройки в `config.yaml`:
```yaml
facility_topology:
  use_default_38_panels: true
  base_ip_prefix: "192.168.1."  # Базовая подсеть
  start_ip_suffix: 10           # С какого IP начинать нумерацию
  default_port: 80
  default_username: "admin"
  default_password: "ВашПароль" # Общий пароль для всех панелей
```

### Правила распределения доступа:
1. **Калитки:** код каждого жильца **всегда автоматически загружается в обе калитки** (Калитка 1 и Калитка 2).
2. **Обычный жилец:**
   - Если указано `Дом: 1`, `Подъезд: 1` — код загружается в **4 панели** (2 калитки + внешняя и внутренняя двери Подъезда 1 Дома 1).
   - Жилец не сможет открыть своим кодом чужие подъезды или другие дома.
3. **Персонал / Охрана / Управляющий:**
   - Если указано `Дом: Все`, `Подъезд: Все` (или `Доступ: Все`) — код загружается во **все 38 панелей**.
4. **Несколько подъездов:**
   - Можно перечислять через запятую, например `Подъезд: 1, 2` или `Доступ: Дом 1, Дом 2`.

## ⚡ Высокая скорость работы (Параллельная синхронизация)

Синхронизация кода с несколькими панелями выполняется **параллельно в пуле потоков (ThreadPoolExecutor)**:
* Запись кода жильца на 4 панели занимает **~0.5–1 секунду**.
* Запись служебного кода на все 38 панелей занимает всего **~1.5 секунды** вместо 40 секунд поочередных запросов.
* Если одна из панелей временно выключена или на техобслуживании, остальные панели успешно обновляются без зависания.

## 🚀 Настройка БЕЗ Google Cloud Console (Google Apps Script)

Если в вашей стране Google Cloud Console недоступен, настройка выполняется за 2 минуты прямо внутри вашей Google Таблицы:

1. Откройте вашу Google Таблицу со списком пользователей.
2. В верхнем меню выберите **«Расширения» (Extensions) → «Apps Script»**.
3. Удалите стандартный текст и скопируйте туда весь код из файла проекта [`google_apps_script/Code.gs`](google_apps_script/Code.gs).
4. Нажмите **Сохранить** (`Ctrl+S`).
5. В правом верхнем углу нажмите **«Начать развертывание» (Deploy) → «Новое развертывание» (New deployment)**.
6. Выберите тип **«Веб-приложение» (Web app)**:
   - **Описание:** `BAS-IP API`
   - **Запуск от имени:** `Я (ваш_email@gmail.com)`
   - **У кого есть доступ:** `Все` (Anyone).
7. Нажмите **«Развернуть»**, предоставьте доступ своему аккаунту и скопируйте полученный **URL веб-приложения** (`https://script.google.com/macros/s/AKfycb.../exec`).
8. Вставьте этот URL в `config.yaml` в поле `gas_web_app_url`:

```yaml
google_sheets:
  backend_type: "google_apps_script"
  gas_web_app_url: "https://script.google.com/macros/s/AKfycb.../exec"
```

## ✉️ Настройка Google Почты (Gmail) без Google Cloud Console

Для отправки писем не нужен Google Cloud Console — достаточно стандартного пароля приложений Google:

1. Перейдите в настройки безопасности аккаунта: [https://myaccount.google.com/security](https://myaccount.google.com/security).
2. Включите **Двухэтапную аутентификацию** (2-Step Verification).
3. В строке поиска найдите **«Пароли приложений» (App Passwords)**.
4. Создайте пароль для домофона и сохраните сгенерированный 16-значный ключ (`abcd efgh ijkl mnop`).
5. Вставьте логин и пароль в `config.yaml`:
   ```yaml
   gmail:
     user: "your_email@gmail.com"
     app_password: "abcdefghijklmnop"
   ```

*После смены кода пользователю отправляется письмо:*
> **Добрый день, ваш код доступа изменен на "123456"**

## 🛠 Команды управления и тестирование

```bash
# 1. Посмотреть всю топологию комплекса из 38 панелей:
python3 main.py list-panels

# 2. Проверить пользователей и количество доступных панелей для каждого:
python3 main.py test-sheets

# 3. Проверить связь с панелями домофонов:
python3 main.py test-panel

# 4. Отправить тестовое письмо на почту:
python3 main.py test-email --to your_email@example.com

# 5. Тестовый прогон без записи на панели и в таблицу (Dry-Run):
python3 main.py run --dry-run

# 6. Боевой запуск (сменит коды тем, у кого прошло 14 дней):
python3 main.py run

# 7. Запустить эмулятор всех 38 панелей для локальной отладки:
python3 main.py run --mock-panel

# 8. Запуск фоновой службы 24/7 (планировщик):
python3 main.py daemon
```

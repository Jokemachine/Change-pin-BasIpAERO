# Руководство по установке и запуску на Windows 10 / 11 / Windows Server

Программа полностью кроссплатформенная и отлично работает на любой версии Windows.

---

## 🚀 Быстрый старт (Установка за 3 шага)

### Шаг 1. Установка Python
1. Скачайте Python с официального сайта: **[https://www.python.org/downloads/](https://www.python.org/downloads/)** (рекомендуется версия 3.10, 3.11 или новее).
2. При запуске установщика **ОБЯЗАТЕЛЬНО поставьте галочку внизу окна:**
   > ☑ **Add python.exe to PATH** (Добавить Python в системные переменные PATH).
3. Нажмите **Install Now**.

---

### Шаг 2. Скачивание проекта
Вы можете:
* Скачать архив проекта с GitHub: зелёная кнопка **Code** ➔ **Download ZIP** и распаковать его в любую папку (например, `C:\BAS-IP-Rotator`).
* Или клонировать через Git:
  ```cmd
  git clone https://github.com/Jokemachine/Change-pin-BasIpAERO.git
  cd Change-pin-BasIpAERO
  ```

---

### Шаг 3. Автоматическая установка (в 1 клик)
В папке с проектом дважды щелкните по файлу:
👉 **`install_windows.bat`**

Скрипт автоматически:
1. Проверит наличие Python.
2. Создаст изолированное виртуальное окружение `.venv`.
3. Установит все необходимые библиотеки (`requests`, `pyyaml`, `schedule` и др.).

---

## 🛠 Настройка IP-адресов панелей и параметров

1. Откройте файл **`panels.yaml`** (в Блокноте, Notepad++ или VS Code) или файл **`panels.csv`** (в Microsoft Excel).
2. Впишите реальные IP-адреса и пароли для ваших 38 панелей домофонов:
   * 2 калитки (`gate_1`, `gate_2`);
   * 4 дома (в Домах 1 и 4 по 3 двойных подъезда; в Домах 2 и 3 по 6 двойных подъездов).
3. В файле **`config.yaml`** проверьте настройки:
   * Ваши Google Apps Script URL и Gmail данные уже вписаны в проект!

---

## 🧪 Проверка и тестирование (Готовые ярлыки `.bat`)

В папке проекта подготовлены готовые батники для запуска двойным кликом мыши:

| Файл | Что делает |
|:---|:---|
| **`list_panels.bat`** | Показывает в консоли красивую таблицу всех 38 панелей с их IP и подъездами |
| **`test_sheets.bat`** | Проверяет связь с Google Таблицей и выводит список жильцов и доступных им панелей |
| **`test_panel.bat`** | Проверяет сетевую доступность вызывных панелей BAS-IP |
| **`run_dry_run.bat`** | **Безопасная симуляция**: покажет, кому пора менять код, сгенерирует PIN-коды, но **не будет ничего перезаписывать** |
| **`run_now.bat`** | **Боевой запуск**: выполняет смену кодов, отправляет письма и обновляет Google Таблицу |
| **`run_service.bat`** | Запускает постоянную службу (проверяет каждые 12 часов, пока открыто окно) |

## ⏰ Настройка автоматического запуска 24/7 на Windows

Чтобы программа работала полностью автономно и не требовала ручного запуска, настройте стандартный **Планировщик заданий Windows (Task Scheduler)**.

### Настройка через Планировщик заданий Windows:

1. Нажмите клавиши `Win + R`, введите **`taskschd.msc`** и нажмите **Enter**.
2. В меню справа нажмите **«Создать простую задачу...»** (Create Basic Task).
3. **Имя:** `BAS-IP PIN Rotator`. Нажмите *Далее*.
4. **Триггер:** выберите **«Ежедневно»** (Daily). Нажмите *Далее*.
5. **Время:** установите ночное время, например, `03:00` (чтобы жильцы получили код к утру).
6. **Действие:** выберите **«Запустить программу»** (Start a program). Нажмите *Далее*.
7. В поле **«Программа или сценарий»** нажмите кнопку *Обзор* и выберите файл:
   * **Вариант без всплывающего окна (рекомендуется):** выберите файл **`run_silent.vbs`** из папки проекта. Он выполнит проверку абсолютно незаметно в фоновом режиме.
   * **Или вариант с окном консоли:** выберите **`run_now.bat`**.
8. **ВАЖНО! В поле «Рабочая папка» (Start in):**
   * Обязательно укажите путь к папке с проектом (например: `C:\BAS-IP-Rotator`).
9. Нажмите *Далее* ➔ *Готово*.

Теперь каждое утро в 03:00 Windows автоматически запустит скрипт, проверит, у кого прошло 14 дней с момента прошлой смены кода, установит новые коды на панели, обновит Google Таблицу и отправит письма через Gmail!

## 🛡 Возможные нюансы и решения (Windows Troubleshooting)

1. **Брандмауэр Windows (Windows Defender Firewall):**
   * Программа делает исходящие HTTP-запросы к панелям BAS-IP (локальная сеть) и к серверам Google (порт 443 HTTPS и порт 465 SSL). Обычно исходящие соединения разрешены по умолчанию. Если на компьютере установлен строгий корпоративный антивирус, разрешите исходящий трафик для `python.exe`.

2. **Русские буквы в консоли:**
   * Все `.bat`-файлы проекта автоматически переключают кодировку консоли на UTF-8 (`chcp 65001`), поэтому имена и адреса на русском отображаются корректно.

3. **Компьютер уходит в спящий режим:**
   * Если планировщик настроен на 03:00 ночи, в свойствах созданной задачи на вкладке **«Условия»** поставьте галочку:
     > ☑ **«Пробуждать компьютер для выполнения этой задачи»** (Wake the computer to run this task).
